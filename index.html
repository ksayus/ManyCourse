ManyCourse（课多多）是一款原生 Android 课表应用。它不做"又一个手输课表 App"—— 而是把各校教务系统的登录与课表接口一个个接进来：填一次学号密码， 姓名、课表、教学周自动同步，配合月历与校园地图，开学第一周不用再对着教务网站截图。

Features

它到底解决了什么问题

核心只有一件事：把"学校的课表"变成"手机上的课表"，并且不用每周手动维护。

🔐

多学校登录

登录页下拉选学校，一所学校一份独立实现。加一所新学校不用改任何界面代码——下拉、持久化、登录分发全由学校清单驱动。

🔄

课表与姓名自动同步

登录成功后按学校分发到对应接口，把课表拉进本地；学生姓名自动写进「我的」页，但你手动改过的昵称不会被覆盖。

🗓️

周视图 + 月历

按星期 × 节次排版并高亮当前课程；月历用彩色圆点显示每天的课程密度，点日期直接看当天安排。

🗺️

多校区校园地图

一所学校多个校区多张图（比如广工 5 个校区）。进页面取一次定位，自动挑离你最近的那个校区的图，也可以手动切换。

♻️

维持登录

登录态（Cookie）用 Android Keystore 密钥 AES-GCM 加密后落盘，冷启动直接进主界面。从不保存密码。

🧊

玻璃拟态界面

Jetpack Compose + Material 3，玻璃底栏、玻璃头部与液体玻璃背景，深色模式自适应。

想让你的学校也进来？

表单登录型的教务系统通常只要一个新文件 + 一行注册：抓包拿到登录地址与两个字段名，复制模板填四行即可。 代码完全开源，欢迎 PR。

带一张校园地图也行

贡献地图只要一张图 + 一行登记（可带多校区坐标），比接接口轻得多。图片放进 res/drawable-nodpi/，再在 SchoolMap.kt 里登记校区即可。

  1. 下载 APK

    点上面的按钮，或用手机浏览器打开本页；APK 会保存到「下载」目录。

  2. 允许安装

  4. 课表自动到位

    进入主界面后课表自动同步；点「我的」可以看到从学校系统同步来的姓名与课程统计。

Build from source

自己构建

需要 JDK 17+ 与 Android SDK（Platform 37）。Gradle 用仓库自带的 wrapper，不用另装。

  1. 克隆并配置 SDK 路径

    local.properties 不进仓库，需要在本机写一份。

    # Windows / PowerShell
git clone https://github.com/ksayus/--ManyCourse.git
cd --ManyCourse
"sdk.dir=D:\\DevelopEnvironment\\AndroidSDK" | Set-Content local.properties
  2. 跑测试并出包

    单测覆盖解析器、密码学、选校区与节次表，秒级完成。

    .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug

# macOS / Linux：./gradlew :app:testDebugUnitTest :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
  3. （可选）出正式签名包

    签名信息从 Gradle 属性读，不写进仓库；不配也能构建，只是产出未签名包。 JDK 20+ 的 keytool 默认生成 PKCS#12，不要再加 -storetype JKS。

    keytool -genkeypair -v -keystore release.p12 -alias manycourse `
        -keyalg RSA -keysize 2048 -validity 10000 `
        -dname "CN=ManyCourse, O=YourName, C=CN"

.\gradlew.bat :app:assembleRelease `
  -Pmanycourse.storeFile=release.p12 `
  -Pmanycourse.storePassword=你的口令 `
  -Pmanycourse.keyAlias=manycourse `
  -Pmanycourse.keyPassword=你的口令
  4. CI/CD 全自动

    推 v* 标签即自动测试 → 签名构建 → 发 Release → 更新本页； master 每次推送都会自动部署这个下载页。

    git tag v1.0.0.4 && git push origin v1.0.0.4

技术栈

Kotlin 2.2 · Jetpack Compose (Material 3) · OkHttp 5 · AGP 9 · Gradle 9.5 · minSdk 31 / targetSdk 37。

没有第三方服务

不依赖任何后端：App 直接与本机网络里的教务系统通信，没有中转服务器，也没有数据上报。

密码学自己写并测了

裸 RSA、金智 CAS 的小端 RSA、国密 SM2/SM3、金智 AES 都在仓库里实现并带单测，不引额外依赖。

关于隐私与安全

App 只把你自己账号在教务系统里的数据取回本机显示，不向任何第三方提供数据，也不做服务端转发； 不保存账号密码，登录态以加密 Cookie 存档保存在本机（Android Keystore + AES-GCM），退出登录时连同课表一起清除。 各校接口可能随时变更，失效时只会表现为"课表空了 / 提示登录过期"，不会损坏数据。
